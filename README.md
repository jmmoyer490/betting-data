# betting-data

Public mirror of odds snapshots (NFL + CFB) produced by the private `betting-pipeline` repo.
Contains market lines only - no bets, no credentials.

- `data/odds_snapshots.csv` - append-only; one row per snapshot / event / book / market / outcome.
- Snapshot types: opener (Mon AM), midweek (Fri), gameday (Sat/Sun AM), manual.
